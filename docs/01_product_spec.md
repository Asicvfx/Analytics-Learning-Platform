# Product Specification (summary)

Analytics & Learning Platform — internal corporate analytics + learning portal.
Single place to open dashboards, explore data, filter, export, and learn how to
use each report. Independent BI system (not a Qlik Sense integration); first
version uses **demo/fake data only**.

## Roles
ADMIN, ANALYST, MANAGER, EMPLOYEE.

## First-version scope
Authentication (JWT), role-based access, dashboard catalog, categories,
dashboard detail with sheets, KPI cards, charts, tables, filters, CSV export,
learning materials/instructions, admin panel (dashboards, categories, users),
audit logs, demo data, clean responsive UI.

## Not in first version
Real corporate data/links, Qlik integration, drag-and-drop builder, real SSO,
VPN, row-level security, Excel/PDF export, scheduled refresh, real AI.

## Demo categories
Revenue, Orders, BIN Analytics, Contacts, Education and Healthcare Objects,
Provider SpeedTest Map, Government Procurement, Sales Tools, AI Tools,
Instructions.

## Demo dashboards
Revenue Overview, Orders Dashboard, BIN Analytics, Contacts Dashboard,
Education and Healthcare Objects, Provider SpeedTest Map, Government Procurement
Analytics, SalesHelper Dashboard.
